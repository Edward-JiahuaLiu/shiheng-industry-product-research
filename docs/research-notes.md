# 报告口径与来源

发布版 PDF 来自已完成的食亨行业与产品研究 Figma 文件，共 12 页。报告中关于食亨产品、公开客户案例、连锁业态与专业数据库的引文保留在每页页底；本文件不替代原页的证据。报告研究过程的完整证据账本保存在本地工作区，公开仓库只带入经过筛选的展示资料。

阅读时请区分三种内容：①食亨官网公开产品与客户案例；②外部研究对行业任务的代理描述，不直接推算市场 TAM；③厨房知识助手的概念推演，需要店主、主厨和分店员工现场试验。Demo 使用虚构番茄炒蛋、宫保鸡丁、红烧肉，不能当作食亨现售功能或任何店铺的标准配方。

研究链条：总部采购任务 → 已有替代路径 → 第二店执行断点 → 主厨确认版知识 → 数据安全门槛 → 与批准卡/搜索比较是否还需要 RAG。
