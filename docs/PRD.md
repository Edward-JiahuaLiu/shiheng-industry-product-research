# PRD｜厨房批准版知识问答手机 Demo

版本：v0.2，2026-09-15。状态：本轮 Demo 实现与验收依据。

## 一句话与验收

主厨在一部手机上采集并批准三道虚构菜的图文/语音知识；分店员工在另一角色视角的手机上，能看到同问句「无检索」与「当前批准版文本 RAG」的答案区别，找不到依据时向主厨求助。演示至少一条成功有据问答、一条未批准不可检索、一条未知关口转主厨。

## 屏幕与信息架构

1. 「主厨 · 建知识」：三菜选项；采集区只突出「资料图」和「口述」，「参照图」为次入口。番茄炒蛋使用文字资料示例图＋备菜/炒制状态参照图；后两菜不重复整组摄影流程。选示例资料图时按钮叫「载入示例 OCR 草稿」，不是“读懂菜品图”；播放合成口述或录音，示例音频可载入预置转写，本机音/图只手工填改。草稿审核区采集后展开；主厨编辑并确认发布 vN。只出现主厨主手机，不画第二手机。
2. 「分店 · 快问」：先展示当前批准版 B1 的 2–3 条短提醒与「看完整卡」；再输入短问句。主要结果区一次只显示一条 RAG 短答、版本/步骤出处与批准参照图，避免手机双栏实验台。评测切换器/对照抽屉再展示 A0 无本店资料、A1 全文入模、A2 检索片段的同题结果，明示 A0→A2 不能证明检索单独收益。资料不足先显示本店卡与「问主厨」；员工点求助后先生成摘要，确认「发送模拟求助」才在右下角出现小主厨手机，显示模拟通知/待回复、非真实推送。上传页绝不显示该小手机。

视觉：沿食亨官网的红色强调、白底与淡红叠底；文本框仍为整洁矩形卡片，气泡只作背景层。厨师工作界面优先，图片用作证据/参照，不用大幅摄影叙事。中文主文字不小于 16px，常用标签不小于 14px；按钮可触摸，角色标签明显。

## 三道虚构菜与关键问句

| 菜 | 例示批准线索（非标准配方） | 员工问题 | 预期 |
|---|---|---|---|
| 番茄炒蛋 | 蛋液中火炒至刚凝固先盛出；番茄炒软出汁后回锅；成品图只供人工参照 | 番茄下锅前，鸡蛋要炒到什么状态？ | 找步骤、引 v1，不捏造分钟/克数 |
| 宫保鸡丁 | 鸡丁先滑炒；酱汁略收后再入花生，保持脆度；示例明确含花生 | 花生什么时候放？ | 找步骤、引 v1；问「花生过敏的人能吃吗？」按已批准含花生事实回答不适合，替代做法转主厨；未记录的其他过敏原不能猜 |
| 红烧肉 | 焯水后煸出油；小火焖至筷子可轻松扎入，再开盖收汁 | 收汁前怎样看肉是否到位？ | 初态拒答，主厨批准后引用当前版判断线索，不推食品安全温度 |

## 交互规则

- 初态番茄炒蛋与宫保鸡丁已有虚构 v1 批准卡，红烧肉待批准：既能立即演示有据问答，也能演示未批准拒答和主厨发布。每次确认发布递增版本，问答只看该菜当前批准版；「重置演示」回到这个固定初态。
- OCR/ASR 本版是「载入示例草稿」：文字资料图对应预置 OCR 文本，示例合成音频对应预置转写；备菜/炒菜/成品参照图绝不 OCR 或自动推出配方。本机新上传/录音只能手工填写/编辑，不能宣传为真实识别。录音可试听、停止和删除；录音不上传服务端。
- 问答先显示批准版 B1。提问后根据所选菜＋问题检索批准版步骤，显示命中/空命中。A0 不访问批准文本；A1 获得全文；A2 获得检索片段；同题/同模型/同温度，只允许这个上下文差异。实验切换器不改变问题；A0 vs A2 只展示“有本店知识”的效果，A1 vs A2 才观察检索方式的区别，但三菜短卡不足以证明大库检索优势。真实 Qwen 可选、默认关闭；模拟回答必须标「离线演示｜预置生成」，不可伪称 AI API 真实返回。
- 批准资料明确写明的关口直接忠实答，如「含花生 → 花生过敏者不应食用」；缺文档、低匹配、未批准、旧版本及未写明的禁忌/食品安全关口不可猜。引导现版卡和「问主厨」；求助消息为本地状态。图片与音频不作为模型输入。
- 当有密钥和明确启用真实模式时，服务端只接受虚构菜白名单与短问句，后端调用 Qwen，前端不能见密钥；不能自动切到收费模式，用户需在百炼控制台开启“免费额度用完即停”且自行确认额度。

## 成功与停止条件

人工演示核查：①三个菜均能采集/编辑/批准；②草稿不出现在问答检索；③员工页先可用 B1 卡，评测 A0/A1/A2 同题且明确区别，RAG 有可核对的当前版出处；④已批准的花生成分该答，未记录的关口不猜；⑤求助的小主厨手机只在员工页「发送模拟求助」后出现，上传页没有第二手机；⑥示例文字资料图、过程参照图与合成音频可打开播放，本机录音权限拒绝后仍能用示例；⑦手机宽度无重叠/截断；⑧无密钥时明确显示模拟模式，有密钥时调用失败可回退但不伪称真实回复。

研究型实验后续才可声称产品价值：比较 B0 原状、B1 批准图文卡、B2 普通搜索、B3 文本 RAG 的忘步→恢复时间、主厨被打断次数、当前版有据回答/正确拒答；按普通/高峰、方言/普通话分层。若 B1 已足够或 B3 不少打断，停把 RAG 当主方案。食品安全/禁忌关口错答、旧版冒充、越权一次即停真实试点。
