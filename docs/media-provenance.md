# Demo 素材出处与使用边界

本页所有菜、配方和媒体都是虚构演示，不含用户家人饭店或食亨客户资料。照片由内置图像生成工具在本轮原创生成；文字资料图由本项目以 SVG 编写，音频由 macOS 中文系统语音从虚构口述稿合成。没有把照片交给 OCR、视觉模型或 RAG 检索。

| 文件 | 生成意图 | 页面用途 |
|---|---|---|
| `tomato-prep.png` | 工作台上分开的蛋液与番茄块，尚未烹炒 | 番茄炒蛋备菜人工参照 |
| `tomato-wok.png` | 中式炒锅中的鸡蛋刚凝固，准备先盛出，番茄尚未下锅 | 炒蛋状态人工参照；“刚凝固先盛出”来自主厨批准文字，不来自模型看图 |
| `tomato-egg.png` | 番茄炒蛋成品 | 完成状态人工回看 |
| `kung-pao.png` | 宫保鸡丁成品 | 另外一道菜的辨认/回看卡，不作为过敏原判断证据 |
| `braised-pork.png` | 红烧肉成品 | 另外一道菜的辨认/回看卡，不作为安全温度判断证据 |

五张照片的生成提示均约束为虚构中国饭店厨房/菜品、可作小卡片、无人物、无品牌和文字；过程两张分别要求“备菜独立食材”和“锅中鸡蛋刚凝固、尚未加入番茄”，避免把最终成品冒充操作依据。工具生成文件的原始副本位于本次 Codex 生成图目录；项目内选用版本在 `public/media/`。

`*-note.svg` 是可读文字资料的演示载体，对应预置 OCR 草稿；三条 `*.wav` 对应预置转写稿，`*.vtt` 是同稿字幕。示例按钮的“读取”均是 UI 模拟，真正 OCR/ASR、音视频质量验收与数据安全设计留待真实试点。
